# Editorial Ownership (Content Model v2)

**Status:** Canonical — Part 2 completion.  
**Rule:** Every editable piece of information has **exactly one owner**. Generated artifacts are **read-only**.

**Why:** Human manuscripts should outlive software versions. Editors need one trustworthy place to care for meaning; machine outputs help the app run but must not silently become the author. See [Content Model definitions](https://github.com/alephbits/alephbits/blob/main/docs/content/CONTENT_MODEL_DEFINITIONS.md) and [DEC-0008](https://github.com/alephbits/alephbits/blob/main/docs/project_memory/decisions/DEC-0008.md).

---

## Ownership table

| Editable piece | Single owner | Not owned by |
|----------------|--------------|--------------|
| Edition prose, quiz, edition metadata, sources, transparency | **`books/<book_id>/<locale>/reading-pack.md`** | `lesson.json`, `quiz.json`, `text.txt`, `book.yaml` |
| Book identity, status/tier, default locale, legacy ids | **`books/<book_id>/book.yaml`** | `reading-pack.md` edition metadata |
| Shared book art (`cover.webp`, `vignette.webp`) | **`books/<book_id>/default/`** | stock `covers/` catalog |
| Locale art override | **`books/<book_id>/<locale>/`** | default/ (override wins) |
| Study protocol | **`studies/<id>/study.yaml`** | pack files |
| Study questionnaire | **`studies/<id>/questions.*.json`** | pack `## Quiz` / `quiz.json` |
| Shared world vocabulary | **`world/dictionary.yaml`** | pack World lists alone |
| Stock cover fallback families | **`covers/catalog.json`** | used only when book has no `cover.webp` |
| Audience / Category / Difficulty | **`reading-pack.md` metadata** | never `book.yaml`; see app [METADATA_MODEL.md](https://github.com/alephbits/alephbits/blob/main/docs/content/METADATA_MODEL.md) |

## Generated (never hand-edit)

| Artifact | Produced by | From |
|----------|-------------|------|
| `lesson.json` | `compile_pack` | `reading-pack.md` (+ book identity from layout / `book.yaml`) |
| `text.txt` | `compile_pack` | `## Text` |
| `quiz.json` | `compile_pack` | `## Quiz` |
| `provenance.json` | `compile_pack` | Transparency + Sources |
| `license.md` | `compile_pack` | Transparency license fields |
| root `manifest.json` | `build_manifest` | discovered packs + editorial Genres |

Markers:

- `license.md` begins with an HTML comment: generated by `compile_pack`
- `lesson.json` / `quiz.json` / `provenance.json` include `generatedBy` + `generatedFrom`

CI enforces read-only via `compile_pack --check` and `validate_pack` compile-drift checks. Hand-editing generated files fails validation.

## `book.yaml` allowed fields

```yaml
book_id: "omqigct2"          # required — permanent identity
created: "2026-07-27"        # book record date
status: "official"           # tier for discovery / manifest
default_locale: "pl"
legacy_pack_ids: ["polish_przerwa"]
legacy_slug: "przerwa"
# optional: writing_system
```

**Forbidden** (owned by `reading-pack.md`):

- `editorial_metadata` (audience, cover_family, difficulty, …)
- `license`
- `author`

---

## Studies vs packs

- Studies reference a book with `book: <book_id>` (permanent id).
- Study questions live only in `questions.*.json`.
- Pack `## Quiz` is for reader comprehension in QuietLibrary — never the study SoT.

---

## Editor workflow

1. Edit `reading-pack.md` and/or `book.yaml` / study files only.
2. `dart run tools/compile_pack.dart --overwrite <locale-dir>` (or `--all`).
3. `dart run tools/build_manifest.dart`.
4. `dart run scripts/validate_pack.dart`.

Do not edit `quiz.json` to “fix a question” — change `## Quiz` in the manuscript and recompile.

## Book visual assets (Part 3)

```text
books/<book_id>/
  default/
    cover.webp      # book-owned shelf cover (preferred)
    vignette.webp   # book-owned title-page art
  <locale>/
    cover.webp      # optional locale override
    vignette.webp   # optional locale override
```

Resolve order (app + sync + bundle):

1. `{locale}/{asset}.{lang}.webp` (rare)
2. `default/{asset}.{lang}.webp`
3. `{locale}/{asset}.webp`
4. `default/{asset}.webp`
5. stock catalog / generated cover (covers only) or none (vignettes)

`covers/catalog.json` is **temporary stock fallback** until books ship their own `cover.webp`.
